# Quit Tracker

A minimal and responsive habit quit tracker that helps users track their streak, quit duration, and previous streak history.

## 🚀 Quick Deployment

If you want to use the app directly:

1. Download all project files.
2. Put all the files into a **single folder**.
3. Upload the folder to **Netlify** and deploy it.
4. Copy the deployed website link.
5. Open the link in **Google Chrome**.
6. Use Chrome's **Add to Home screen / Install app** option.
7. The app will then work properly from your home screen.

> **Important:** Keep all project files together in the same folder when deploying.
